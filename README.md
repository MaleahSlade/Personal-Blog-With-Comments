Project Description: This is a community reading log designed for my book review site, The Curious Commuter Lit List. 
The purpose of this feature is to encourage users to log the minutes they read while on their commute. I will eventually
require users to create an account to write log entries. I would also like to give users the option to not only make public comments 
but also have private journal-style entries on their personal profiles. 

The reading log allows users to add the following pieces of information:

Book Title
Author
Date
Minutes
Genre
Subgenre
Comments
Submission UserName

Users can edit and delete their submissions after posting. Submissions are saved in local storage. 

My favorite part about the log is that the inputs expand, allowing users to elaborate and write as much as needed for their entries. 

My development process is entirely based on the structure and design of the user interface. I create all of the input fields and determine which pieces
of information are most important. This gives me a clear idea of how I want to connect the HTML elements to the DOM. Then I gradually add the event listeners
from one input field to the next until all are accounted for. I test the form in the console until I resolve all errors.
